## 0.1.0 — 2026-11-04

Initial versioned companion release: Python experiments and recorded results,
Lean development and audited statement inventory, reader documentation, slides,
and tools for generating publication outputs from an explicitly supplied private
manuscript checkout. This version accompanies book proof 0.1.0.

Versions follow MAJOR.MINOR.PATCH. A change to the public mathematical or code
interface can require a major version; substantive compatible additions use a
minor version; corrections use a patch version. The book and companion versions
may advance independently after this initial pair. The book records the exact
companion version it uses. Tags are named `vMAJOR.MINOR.PATCH`.
